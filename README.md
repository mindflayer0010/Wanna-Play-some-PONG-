# Wanna Play Some Pong?

A simple browser-based Pong game built entirely with HTML, CSS, and JavaScript.

This project started as a quick one-hour experiment over coffee — no frameworks, no fancy engines, just a canvas, some logic, and a bit of physics that somehow worked.

## Features

- Classic Pong gameplay — two paddles, one ball, endless fun
- Basic collision and scoring system
- Two-player keyboard controls
- Clean, minimal layout with zero dependencies
- Short, readable code for easy learning

## Why I Built This

Made purely for fun and to explore how simple games work under the hood.
It’s a small reminder that even simple ideas can teach you a lot about rendering, physics, and interactivity on the web.

## Tech Stack

- HTML5 Canvas
- Vanilla JavaScript
- CSS
